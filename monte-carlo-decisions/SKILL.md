# 概率推演 · 蒙特卡洛模拟器

## 定位

确定性计算告诉你NPV是-4.16亿。蒙特卡洛告诉你：**-4.16亿只是平均值，真实结果有73%的概率比这更差。**

这不是一个独立的决策Skill，而是**所有其他Skill的量化增强层**。任何需要回答"有多大把握"的场景，蒙特卡洛上场。

## 工作流

1. **确定输入变量与分布**（读取 `references/蒙特卡洛模拟器.md`）：
   - 识别3-5个最不确定的关键变量
   - 为每个变量设定分布（正态/三角/均匀）
   - 参数来源：历史数据/行业基准/专家估计
   - ⚠️ 分布假设质量决定模拟质量——对前3大不确定变量做分布校准

2. **5000次模拟运行**：
   - 每次从各变量分布中随机抽样
   - 计算目标指标（NPV/IRR/DSCR等）
   - 生成完整概率分布

3. **结果解读**：
   - 期望值、标准差、偏度
   - 亏损概率（NPV<0的概率）
   - 90%/95%置信区间
   - 龙卷风图：哪个变量对结果影响最大

4. **关联到具体决策框架**：
   - 结果嵌入对应的决策Skill输出
   - 如：生存诊断 → "在最坏10%情景下，现金___个月耗尽"

## 与其他Skill的配合

```
创始人-生存诊断器 + 蒙特卡洛 = "你有73%的概率在4个月内耗尽现金"
CFO-投资决策器 + 蒙特卡洛 = "这个项目有41%的亏损概率"
VC-早期判断器 + 蒙特卡洛 = "全损概率65%，但10%概率百倍回报"
```
